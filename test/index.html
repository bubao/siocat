Socket.IO Test Server

Server Information

This is a test Socket.IO server for siocat development and testing.

Server is running and ready to accept connections.

Testing with siocat

To test with siocat, use the following commands:

Basic Connection

node bin/siocat.js http://localhost:3000

Sending Events

Once connected, you can send events in the siocat TUI:

emit chatMessage {"message": "Hello World"}
emit joinRoom {"room": "general"}
emit customEvent {"data": "test value"}

Supported Events

  • chatMessage - Send a chat message
  • joinRoom - Join a room
  • customEvent - Send a custom event (supports acknowledgment)
